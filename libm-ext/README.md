## Trigonometric functions

- `sinpi` for $\sin(\pi x)$ (`f64`)
- `cospi` for $\cos(\pi x)$ (`f64`)
- `sinpif` for $\sin(\pi x)$ (`f32`)
- `cospif` for $\cos(\pi x)$ (`f32`)
- `sincospi` for $\sin(\pi x)$ and $\cos(\pi x)$ (`f64`)
- `sincospif` for $\sin(\pi x)$ and $\cos(\pi x)$ (`f32`)
